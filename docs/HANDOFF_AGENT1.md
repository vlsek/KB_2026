Читать вместе с `docs/LEGEND_MEDALS_FINDINGS.md`, `OWNER_TODO.md`, `docs/WORKLOG.md`. Общаться по-русски; `.ps1` только ASCII; установка скриптами от администратора, команды владелец вставляет по одной. Владелец сам запускает игру и тестирует. Пуш из сессии агента 1 был закрыт прокси (403), владелец заливает zip руками; токен из чата не использовать.

## Состояние
- Готово и проверено в игре: мод 32:9 (`32_9-nsf`), широкая панель карты, журнал по центру, камера; 6 кнопок-слотов в окне героя (`mods/medal-slots-ui/hero.ui`, слоты `slot_13..18`); предмет-медаль через `hero.txt` start items (иконка `heroitem_quest_medal.png`, `propbits=quest`, тип «Квестовый»); Lua-выдача `mods/ach-lua`.
- Не принимают медаль: слоты 13..18 (в `hero.txt` для них нет правил `slots`).
- Проба карты (`probe2`): поля `hero_attack_num/defense/intellect/money/mana/rage/level/ldrshp1` отдают числа, `hero_crystals_num`, `mc1` пустые. Статистики боёв полями не показать, только Lua. Шрифт полей не настраивается.
- Lua не умеет менять UI (в скриптах нет такого API), поэтому слоты-медали надо делать настоящими слотами экипировки.

## Находки по слотам (slot_dump.txt)
- `hero.txt`: блок `slot_bgs { тип=фон.png/ключ_подсказки }`, у каждого класса `slots { 1=helmet 2=weapon 3=armor 4=boots ... }`; типы: weapon, shield, boots, artefact, regalia, helmet, belt, armor и сочетания через запятую.
- `config.txt` `propbits`: wife 1, map 2, quest 4, medal 8, moral 0x10, container 0x20, nobody 0x40 (дальше в дампе не видели). `propbits=medal` у предмета Logic.hero_add_item отвергает.
- Тест #1 (`mods/ach-lua/tests/kb_slot_test1.ps1`): слоты 13..18 = тип `artefact`, медаль `propbits=artefact`. Ждём результат: принимает ли слот медаль. Если да - следующий шаг: отдельный тип `medal` в `slot_bgs` + `slots`, проверить `propbits` для него; автонадевание Lua (`Logic.hero_lu_item_on_body`), запрет снятия, замена при повышении ранга.

## План (желания владельца)
Слоты только под медали-ачивки; медаль надевается сама, снять нельзя; при апгрейде заменяется; подсказка слота «какая медаль, за что»; окно «медаль получена» (Game.InvokeMsgBox / InfoHint).
