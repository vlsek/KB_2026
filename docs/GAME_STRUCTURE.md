Источник: вывод `ls` из PowerShell, который прислал владелец проекта.
**Фрагмент неполный**: папка `loc_data` целиком, а из `models` только начало по алфавиту
(до `collision_hellstones04.cms`, т.е. примерно буквы A–H). Остальные папки игры пока неизвестны.

Пометка ❓ — предположение по именам файлов, не проверено.

## `models\` — модели (фрагмент A–H)

### Расширения
| Расширение | Что вероятнее всего ❓ | Примеры |
|---|---|---|
| `.bms` | статичные модели: здания, деревья, декор, детали арен | `abbey.bms`, `building_temple.bms` |
| `.bma` | модели с анимацией: существа, герои, сундуки, флаги | `archer.bma`, `chest_blue.bma` |
| `.bsa` | анимация/скелет (в фрагменте всего один) | `building_mill01_idle.bsa` |
| `.cms` | коллизионные модели, имя `collision_<модель>.cms` | `collision_abbey.cms` |

Формат файлов на уровне байтов пока не изучен — это отдельная исследовательская задача.

### Семейства имён (префиксы)
| Префикс | Что это ❓ |
|---|---|
| `ah_*` | персонажи/существа приключенческой части (имена героев и NPC) |
| `arena_*` | объекты боевых арен (замок, гномы, орки, некроманты, инферно, пауки, лёд…) |
| `building_*` | строения на глобальной карте и в городах |
| `castle_*` | замки по расам (human, dwarf, elf, demon, dead, orc…) |
| `cave1_*`, `cave_*` | пещеры: камни, корни, грибы, скелеты |
| `auttree*`, `arena_auttree*` | деревья (варианты `dark`, `fluffy`, `red`, `yellow`) |
| `bridge_*` | мосты |
| `chest*`, `bigchest*` | сундуки (`_nos` — вариант без чего-то ❓) |
| `book*` | книги (школы магии: chaos, distor, order, death, life, illusion) |
| `dead*`, `elf*`, `dwarf*`, `demon*` | декор биомов и рас |
| `collision_*` | коллизии для моделей выше |

### Наблюдения
- Почти у каждого объекта карты есть пара `collision_<имя>.cms`. У существ коллизии очень маленькие (~450–470 байт).
- Крупные коллизии: `collision_demonisland01..04.cms` (100–133 КБ), `collision_head_bigturtle.cms` (~99 КБ) — сложные уровни/острова.
- Почти все файлы датированы 01.08.2008. Исключение в видимой части: `building_dwarflab01.bma` (04.09.2017) — единственная модель, правленая позже.
- У существ часто есть варианты: `_death`, `_red`, `_white`, `_egg01`, `high` (вариант высокой детализации? ❓).
- Отдельно стоят `ah_free_*` — вероятно, свободные юниты/NPC ❓.

## Как получить полный снимок
Владелец запускает в корне игры:

```powershell
powershell -ExecutionPolicy Bypass -File .\dump_structure.ps1 -GameRoot .
```

Скрипт — [`tools/dump_structure.ps1`](../tools/dump_structure.ps1). Он создаёт папку `kb_structure`:
- `summary.csv` — по каждой папке и расширению: число файлов и суммарный размер;
- `top_levels.txt` — дерево папок до глубины 3;
- `full_listing.csv` — полный список файлов (путь, размер, дата).

Достаточно прислать `summary.csv` и `top_levels.txt`; полный список — по необходимости.
В выводе только относительные пути, личных данных там нет.
