# 🎮 Заметки о структуре игры

Собрано из мода `32x9-ui` (v4) и списков файлов игры. Структура папок и файлов — в [GAME_STRUCTURE.md](GAME_STRUCTURE.md). Дополняйте проверенными фактами; непроверенное помечайте ❓.

## Расположение (игра King's Bounty: The Legend)
- Моды интерфейса: `<папка игры>\data\mods\16_9-nsf\` — мод 32:9 копируется поверх.
- Камера: `<папка игры>\sessions\base\ses\camera.txt` (перед заменой делать `.bak`).

## Разрешения
- `resolutions.txt` — формат `соотношение=ширинаxвысота`:
  `4.3=1280x960`, `5.4=1280x1024`, `8.5=1680x1050`, `16.9=1680x945`, `32.9=3360x945`.
- `forms.txt` — привязка экранов к `.ui` файлам для каждого разрешения
  (например `3360x945=credits_3360x945.ui`).

## Камера (`camera.txt`)
- Изменено модом: `DIST_MAX 18 → 36`, `ZFAR 90 → 150`.
- Блок `ClipDist` задаёт дальность отсечения моделей/теней (Big/Average/Small).
- Параметры арены (`ARENA_*`) отдельно от основной камеры.

## Файлы интерфейса мода
- `*_3360x945.ui` — экраны: map, arena, start, new_game, intro, loading, town, credits.
- `mainpanel_bg_3360_a/b.png` — нижняя панель (1682×250 и 1680×250), лежат рядом с `.ui`.

## Как устроена панель карты (v4)
- `map_*.ui` — логическое разрешение 1680×945 (16:9) / 3360×945 (32:9); движок масштабирует интерфейс одинаково по осям.
- Нижняя панель — одна картинка `mainpanel_bg_*.png` с «дырками» под слоты, кнопки и миникарту; сами слоты/кнопки — отдельные объекты `.ui` поверх неё.
  Поэтому увеличение блока = перерисовка куска панели + пересчёт координат объектов.
- Блоки панели в 32:9: левый (деньги) у левого края, центральный (герой, слоты, 4 кнопки) по центру, миникарта у правого края; промежутки заполнены каменным парапетом с плющом и синим полем (генерация — Claude, скрипты не в репозитории).

## Окна без 32:9-варианта (известная проблема)
Журнал заданий и другие окна (см. GAME_STRUCTURE.md) берут `ui=` по умолчанию и встают у левого края. Решение: сделать `*_3360x945.ui` (сдвиг по центру) и строки `3360x945=` в `forms.txt`. Нужны оригинальные `.ui` из `data.kfs` (`tools/extract_ui.ps1`).
