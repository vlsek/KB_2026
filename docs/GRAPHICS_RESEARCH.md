# Графика: обёртки и настройки (агент 5)

Статус: исследование + план проверки. В игре НЕ проверено (проверяет владелец).
Метка ❓ - гипотеза, не подтверждено.

## Что известно из файлов игры (Legend EE, `default.ini` / `game.ini`)
- Рендер Direct3D 9 с шейдерами `ps20` (`sets ~r_path "ps20"`) ❓ (exe не смотрели; по настройкам это D3D9).
- Анизотропия: `r_filter` 0=билинейная, 1=трилинейная, 2..5 = aniso 2/4/8/16. Сейчас в `game.ini` стоит **2** (aniso 2).
- Сглаживание: `r_fsaa` (0 - нет, 2 - аппаратное), плюс `r_fsaa_h_sample / v_sample` (множитель буфера, 2.0 в default.ini).
- Тени: `r_shadowmap_landscape` (в default.ini 0), `shadowresolution` (в game.ini 1024), `r_shadowmap_4sample`, `r_blur_shadowmap`.
- Вода: `r_water` / `r_water_quality`; мип-уровни: `r_picmip`, `r_skipmip_*`; туман `r_fog`.
- Дальность: `camera.txt` (`ZFAR`, `ClipDist`) - уже расширено нашим модом; `r_clip_distance` в `game.ini`.
- Игра пишет настройки в `game.ini` (перекрывает `default.ini`): правим именно его, с бэкапом.

## Обёртки (что искали в сети)
| Вариант | Суть | Для нас |
|---|---|---|
| **DXVK** (`d3d9.dll` рядом с exe) | D3D9 -> Vulkan, есть и на Windows, и на Linux/Proton | Основной кандидат для Windows 10/11 и Steam Deck; 32-битная сборка (игра 2008 г., ❓ 32-бит) |
| **dgVoodoo2** | Старые DirectDraw/Direct3D -> D3D11/12, заявлена поддержка D3D8-9 | Запасной вариант; даёт свои настройки сглаживания/фильтрации; closed-source |
| dgVoodoo2 + DXVK | цепочка D3D9 -> D3D11 -> Vulkan | Только если по отдельности артефакты; на форумах описан как рабочий для некоторых игр |
| WineD3D | реализация в Wine | Fallback на Linux |

Зачем вообще: на новых видеокартах нативная D3D9 может деградировать (пример из обсуждений - Intel Arc, где D3D9 идёт через эмуляцию). Обёртка - способ получить стабильность и Vulkan на Steam Deck.

## План проверки (для владельца, по одному пункту, с откатом)
Перед началом: скопировать `game.ini` в `game.ini.bak`.
1. **Базовая линия:** скриншот карты и арены + FPS (текущие настройки).
2. **Анизотропия 16x:** в `game.ini` `r_filter 2` -> `r_filter 5`. Скриншот, сравнить дальние текстуры земли.
3. **Тени:** `shadowresolution 1024` -> `2048` (потом `4096`); `r_shadowmap_landscape 0` -> `1` (тени от ландшафта). Смотреть FPS и артефакты.
4. **Сглаживание:** `r_fsaa 0` -> `2` (если игра запустится и не поплывут тени/вода - ❓ в D3D9 с шейдерами бывает конфликт).
5. **vsync / частота:** `r_vsync 1`, при необходимости `r_refresh_rate` = частота монитора.
6. **DXVK:** положить `d3d9.dll` (32-бит) рядом с exe, запустить, сравнить FPS/артефакты/вылеты; откат - удалить dll. Файл `dxvk.conf` для анизотропии и лимита FPS - по документации DXVK ❓ (имена опций уточнить при установке).
7. **dgVoodoo2** - только если п.6 дал проблемы; настройки через `dgVoodooCpl.exe`.

В каждом пункте результат записывать так: что менял / FPS до-после / что видно на скриншоте. По итогам - готовый пресет `mods/gfx-preset` с инструкцией и откатом.

## Источники (поиск, не проверялись на нашей игре)
- GameTechWiki: сводка обёрток (dgVoodoo2: Direct3D 8-9 -> D3D11/12; DXVK: Direct3D 9-11).
- Обсуждения VOGONS: связка dgVoodoo2 + DXVK бывает работает лучше, чем DXVK один (на конкретных играх); автор dgVoodoo2 не планирует D3D9 как выходное API.
- Обсуждения VOGONS: на новых Intel-GPU D3D9 нативно не поддерживается, нужна обёртка.
