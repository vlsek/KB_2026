Статус: план и инструменты готовы, `status:needs-test`. В игре ничего не проверялось, апскейлер и texconv у меня не запускались (тест конвейера - на заглушках и синтетических DDS).

Внутри `textures.kfs` по именам: **1097 `*_diff.dds`** (цвет, 455 МБ), 200 `*_spec.dds` (блеск, 30 МБ), 170 без суффикса (окружение, 31 МБ), 422 `fx*` (частицы, 14 МБ), 42 служебных (вода, кубы), 19 `_mask/_bump/_height`. ## Чем апскейлить (проверено поиском 2026-11-26, из моих знаний + источники)
- **chaiNNer** (бесплатный, графы, пакетная обработка) + модели с **OpenModelDB** (`openmodeldb.info`): там есть теги «Game Textures» (набор данных из игровых текстур) и «DDS» (модель умеет убирать артефакты DDS-блочного сжатия). Именно на DXT-текстурах 2008 года блочные артефакты - главная беда, поэтому берите модели с тегами DDS/JPG-compression, например семейства Nomos/LSDIR (4xNomos8kSC, 4xLSDIRCompactC3 - выпускает Phhofm) ❓ конкретную лучшую модель надо выбрать глазами на 10-20 текстурах.
- **Real-ESRGAN (ncnn-vulkan)**: переносимая программа без Python, работает на любой видеокарте с Vulkan, пакетный режим из командной строки. Это то, что вызывает мой конвейер по умолчанию. Автор одного из свежих портов (Silent Hill 1, ноябрь 2026) использует Real-ESRGAN и сам советует **x2**, хотя доступно до x4.
- **Upscayl** (GUI-обёртка над Real-ESRGAN) - если нужно «просто попробовать на картинке». Topaz Gigapixel - платный, красиво, но не скриптуется так удобно; для 1000+ файлов не нужен.
Мой совет: **сначала Real-ESRGAN x2 на 20 файлах** (быстро, видно эффект), затем, если картинка «пластиковая», выбрать модель в chaiNNer (OpenModelDB) и подставить через `--upscaler-cmd`.

## Правила для игровых текстур (иначе будут артефакты)
1. **Альфа-канал отдельно**: апскейлим только RGB, альфу растягиваем Lanczos (конвейер так и делает).
2. **Не апскейлить**: `fx*` (частицы), `*_spec` (блеск; нейросеть выдумывает шум), `*_mask/_bump/_height` (данные, не картинки), воду, кубы, небо (отдельный этап), 4096-текстуры.
3. **Формат назад только DXT1/DXT3/DXT5** (как был): игра 2008 года на DirectX 9, BC7/BC6 она не поймёт. Mip-уровни пересобираем (`texconv -m 0`).
4. **Размер важнее красоты: игра 32-битная.** Кандидатов (diffuse/other, сторона <= 1024) ~1257 файлов, 382 МБ. Апскейл x2 увеличивает объём в 4 раза (~1,5 ГБ), а `kb.exe` 32-битный. Риск вылетов по памяти. Поэтому: начинать с подмножества (замки, здания, окна, ворота, арена - `--include`), смотреть на потребление памяти и вылеты; `x1.5` и/или «только то, что на экране чаще всего» ❓. Патч «Large Address Aware» для `kb.exe` может поднять потолок до 4 ГБ, но это правка exe, делаем только осознанно и на копии.
5. **Интерфейс отдельно и позже.** Фоны меню (`start_bg_1680.png` и др.) готовы к 1680 px, а 32:9-мод держит координаты форм в пикселях: если увеличить PNG, не зная, масштабирует ли его движок под форму, поедет раскладка ❓. Пока UI не трогаем.

## Главный неизвестный вопрос: подхватит ли игра подменённый файл?
Мод 32:9 кладёт `.ui` и `.png` просто в папку `data\mods\32_9-nsf\` и игра их берёт (проверено агентом 1). Для `.dds` из `textures.kfs` это **не проверено** ❓. Поэтому первый шаг - проба: конвейер умеет «покрасить» одну текстуру в красный без нейросети (`--probe`). Положите результат в `data\mods\<папка>\` тестовой копии и посмотрите, стала ли текстура красной. Если нет - вариант Б: упаковать в `.kfs` (zip) с `.txt`-манифестом по образцу модов в `data\mods` (формат манифеста мода смотреть в `KBMaster_*.txt`).

## Порядок (всё на тестовой копии игры)
1. `kb_texture_inventory.py` на папку игры - получить `SUMMARY.md` с реальными размерами (5 минут).
2. `kb_texture_upscale.py run ... --probe castle_wall_diff.dds` - подменить одну текстуру красной (имя текстуры возьмите любое из `inventory.csv`, которое точно видно на карте), проверить, что игра её подхватывает.
3. `kb_texture_upscale.py run ... --scale 2 --limit 20` - пробный апскейл, сравнить глазами до/после.
4. По результату: выбрать модель, расширить `--include`, следить за памятью, затем небо и (осторожно) интерфейс.

## Инструменты (в репо)
- `tools/kb_texture_inventory.py` - опись текстур по заголовкам DDS/PNG/TGA, классы, форматы, оценка памяти.
- `tools/kb_texture_upscale.py` - конвейер: kfs -> DDS -> PNG -> нейросеть -> DDS (тот же формат, новые mip) -> папка `mod`. Умеет `--dry-run`, `--probe`, продолжение после остановки.
Установка: `pip install pillow`; `texconv.exe` - https://github.com/microsoft/DirectXTex/releases ; `realesrgan-ncnn-vulkan` - https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases .
