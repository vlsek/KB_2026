# 🔎 Что нашлось при сравнении игр серии с Legend (Claude, 2026-11-25)

Источник: общий манифест владельца (`kb_manifest.py` на папку со всеми играми: 180 619 файлов, из них 152 830 внутри 90 архивов `.kfs`), разрезан `tools/kb_split.py`. Отчёты по парам: [docs/reports/](reports/). Сопоставление по имени файла (без папки и архива), содержимое сравнивается по CRC32. **Содержимого файлов я не видел, только имена, размеры и даты.** Всё, что выведено из размеров и имён, помечено ❓.

## Выводы
1. **Медали - это данные плюс Lua, и они начались уже в Crossworlds** (`medals.txt`, `addon_rewards.lua`, строки в `*_rewards.lng`). Иконки в WotN называются `0heroitem_medal_*.png` (110 картинок) ❓ - похоже, медали там лежат у героя как предметы. Это ровно «путь B» из `ACHIEVEMENTS_PLAN.md`, и образцы можно брать из Crossworlds: он самый маленький и ближе всего к Legend по движку.
2. **Достижения в смысле `achievements.txt`, форм и Steam есть только в WotN и Dark Side.** В Dark Side лежит одиночный скриптовый пример `achievement_large_entourage.lu` (2,3 КБ) ❓ - готовая модель «одно достижение = один скрипт».
3. **Статистика растёт от игры к игре**: `records.txt` 11,3 КБ (Legend) -> 14,9 (CW) -> 19,2 (DS) -> 21,6 (WotN) ❓. В новых играх больше счётчиков, их список - источник для идеи владельца про статистику прохождения.
4. Файл `sessions/base/ses/achievements.txt` в Legend (993 Б, дата 24.11.2026) - наш тестовый мод, не часть игры. Оригинального достижения в Legend нет, это согласуется с `EXE_FINDINGS.md`.
5. В Dark Side есть тестовая локация `medal_testing` (`medal_testing.*.loc`) ❓ - служебная карта разработчиков для проверки медалей.

## Что нужно прочитать, чтобы идти дальше
