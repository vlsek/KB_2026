# 🧬 Сравнение игр серии по содержимому `.kfs` (Claude)

Зачем: дампы папок (`docs/dumps/`) показывают только файлы на диске, а в новых играх почти вся логика и интерфейс лежат внутри `.kfs` (это zip, см. [KFS_FORMAT.md](KFS_FORMAT.md)). Эти три инструмента работают с оглавлением архивов без распаковки и отвечают на вопросы «что есть в WotN/Dark Side/Crossworlds, чего нет в Legend» и «где в играх встречается слово X».

Нужен Python 3 (без сторонних библиотек). Файлы игр в репо не кладём, в отчётах только имена, размеры и статистика.

## 0. Без Python: один запуск на все игры (Агент 2)

Если Python не стоит, используйте `tools/Get-KBManifest.ps1`. Он запускается **один раз** в папке, где лежат папки со всеми играми, сам находит игры, читает оглавление каждого `.kfs` (имя, размер, CRC32), сравнивает все игры с Legend и пишет отчёт.

```
cd "D:\Games\KB"
powershell -ExecutionPolicy Bypass -File "<путь к репо>\tools\Get-KBManifest.ps1" -GamesRoot .
```

Результат: папка `kb_manifests\` рядом с играми:
- `REPORT.md` - что есть только в новых играх (по типам и по архивам), новые скрипты и данные, файлы с тем же именем, но другим содержимым, имена про достижения и статистику;
- `<игра>.items.csv` - полный список (диск и внутри `.kfs`), `new_in_<игра>.csv`, `changed_in_<игра>.csv`;
- `kb_manifests.zip` - всё это одним файлом, его можно прислать/залить в `docs/dumps/`.

Имена игр определяются по названию папки: `legend`, `crossworlds`, `red_sands`, `wotn`, `dark_side`, `armored_princess`. Полезные ключи: `-Hash none` (быстрее, но без сравнения содержимого внешних файлов), `-Include '*Legend*','*North*'`, `-Base legend`, `-CompareOnly` (пересобрать отчёт из готовых csv). Игры не изменяются. Сопоставление идёт по имени файла без папки и архива, как в `kb_compare.py`. Проверено на синтетических данных (pwsh 7); на реальных играх не запускалось (`status:needs-test`).

## 1. Манифест игры
```
python tools/kb_manifest.py "<папка игры>" --name legend --out kb_manifests
```
Имена: `legend`, `crossworlds`, `red_sands`, `wotn`, `dark_side`.
В манифест попадают обычные файлы (путь, размер, первые 16 байт, хэш, CRC32 до 8 МБ) и **содержимое каждого `.kfs`** (`data/data.kfs!/ses/items.txt`, размер, CRC32). Режим `--hash none` быстрее, но без CRC сравнение содержимого не работает. Папку `kb_manifests/` в репо не коммитим (она локальная).

## 2. Сравнение
```
python tools/kb_compare.py kb_manifests/legend.manifest.json kb_manifests/wotn.manifest.json --out report_wotn.md
```
Первая игра - база. Файлы сопоставляются по имени (без папки и архива). В отчёте:
- какие расширения есть в каких играх;
- у обычных файлов: совпадают ли сигнатуры форматов;
- сколько файлов одинаковых, сколько с тем же именем, но другим содержимым, и сколько совсем новых;
- новые скрипты и данные (кандидаты на перенос), с путями внутри архивов;
- те же имена с другим содержимым (где игры разошлись).

## 3. Поиск по тексту, включая архивы
```
python tools/kb_grep.py "<папка игры>" achievement steam -i --out dark_side_grep.txt
python tools/kb_grep.py "<папка игры>" "SteamAPI|achiev" --regex --list-only
```
Ищет в `.lua`, `.txt`, `.ui`, `.ini` и других текстовых файлах, в том числе внутри `.kfs`; понимает UTF-8, cp1251 и UTF-16 с BOM. Аналог `search_kfs.ps1`, но не требует PowerShell и ищет и по обычным файлам. Вывод содержит строки из игры, поэтому в репо его целиком не коммитим: в доки идут только имена файлов и 1-2 коротких примера.

## Статус
Проверено только на синтетических данных (два «игры» из zip). На реальных играх не запускалось (`status:needs-test`).

## 4. Все игры одним манифестом и разрезание (Claude, Python)
```
python tools/kb_manifest.py "D:\Games\KB" --name all --out kb_manifests
python tools/kb_split.py kb_manifests\all.manifest.json
python tools/kb_compare.py kb_manifests\legend.manifest.json kb_manifests\wotn.manifest.json --out report_wotn.md
```
`kb_split.py` режет общий манифест по папкам игр. Этим способом владелец уже получил отчёты: [docs/reports/](reports/), выводы - [SERIES_FINDINGS.md](SERIES_FINDINGS.md). Запуск на реальных играх подтверждён (180 тыс. файлов, ошибок 0).

## 5. Достать несколько файлов-образцов
```
python tools/kb_extract.py "<папка игры>" --out ref\crossworlds --name addon_rewards.lua medals.txt
```
Достаёт файлы по точному имени из обычных папок и из `.kfs` (без распаковки целиком, файлы больше 2 МБ пропускаются). Результат - файлы игры, в репо их не коммитим.
