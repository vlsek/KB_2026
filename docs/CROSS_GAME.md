# 🧬 Сравнение игр серии по содержимому `.kfs` (Claude)

Зачем: дампы папок (`docs/dumps/`) показывают только файлы на диске, а в новых играх почти вся логика и интерфейс лежат внутри `.kfs` (это zip, см. [KFS_FORMAT.md](KFS_FORMAT.md)). Эти три инструмента работают с оглавлением архивов без распаковки и отвечают на вопросы «что есть в WotN/Dark Side/Crossworlds, чего нет в Legend» и «где в играх встречается слово X».

Нужен Python 3 (без сторонних библиотек). Файлы игр в репо не кладём, в отчётах только имена, размеры и статистика.

## 1. Манифест игры
```
python tools/kb_manifest.py "<папка игры>" --name legend --out kb_manifests
```
Имена: `legend`, `crossworlds`, `red_sands`, `wotn`, `dark_side`.
В манифест попадают обычные файлы (путь, размер, первые 16 байт, хэш, CRC32 до 8 МБ) и **содержимое каждого `.kfs`** (`data/data.kfs!/ses/items.txt`, размер, CRC32). Режим `--hash none` быстрее, но без CRC сравнение содержимого не работает. Папку `kb_manifests/` в репо не коммитим (она локальная).

## 2. Сравнение
```
python tools/kb_compare.py kb_manifests/legend.manifest.json kb_manifests/wotn.manifest.json --out report_wotn.md
```
Первая игра - база. Файлы сопоставляются по имени (без папки и архива). В отчёте:
- какие расширения есть в каких играх;
- у обычных файлов: совпадают ли сигнатуры форматов;
- сколько файлов одинаковых, сколько с тем же именем, но другим содержимым, и сколько совсем новых;
- новые скрипты и данные (кандидаты на перенос), с путями внутри архивов;
- те же имена с другим содержимым (где игры разошлись).

## 3. Поиск по тексту, включая архивы
```
python tools/kb_grep.py "<папка игры>" achievement steam -i --out dark_side_grep.txt
python tools/kb_grep.py "<папка игры>" "SteamAPI|achiev" --regex --list-only
```
Ищет в `.lua`, `.txt`, `.ui`, `.ini` и других текстовых файлах, в том числе внутри `.kfs`; понимает UTF-8, cp1251 и UTF-16 с BOM. Аналог `search_kfs.ps1`, но не требует PowerShell и ищет и по обычным файлам. Вывод содержит строки из игры, поэтому в репо его целиком не коммитим: в доки идут только имена файлов и 1-2 коротких примера.
