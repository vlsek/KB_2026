# medals-panel - панель наград справа от окна героя (32:9)

Автор: агент 2. Статус: **needs-test**. Идея владельца (27.11): на мониторе 32:9 места полно, слоты медалей не должны сидеть посреди инвентаря - вынести их правее окна героя.

## Что делает
- Окно героя в режиме 3360x945 становится «явным» (как журнал заданий): все объекты оригинального окна 1280x960 сдвинуты на (+1040, -8), окно стоит по центру экрана. Внутри окна ничего не меняется.
- Шесть слотов `slot_13..18` убраны из окна и стоят в отдельной панели **справа от окна** (x 2340..2770, y 60..632 в координатах 3360x945): слева слот, справа название семьи медали и пороги.
- Фон панели (`medals_panel_bg.png`) нарисован нами, без игровой графики. Подписи в нём: Золотой запас, Лидерство, Уровень героя, Мана, Ярость, Задания - пороги официальные (Steam) из `docs/LEGEND_OFFICIAL_ACHIEVEMENTS.md`. Это **картинка**: если семьи медалей изменятся, пересобрать `python make_panel.py` (подписи в списке `FAMILIES`).
- Для разрешения 3360x945 в блок `herwin` файла `forms.txt` мода добавляется строка `3360x945=hero_3360x945.ui` (остальные разрешения не затронуты).
- Схема: `preview.png`.

## Установка (скрипт, от администратора, если игра в Program Files)
```powershell
.\install.ps1 -GameDir "<папка KB The Legend EE>"
```
Нужна папка мода 32:9 `data\mods\32_9-nsf` с `forms.txt`. Скрипт делает бэкап `forms.txt.kb2026mp.bak`, добавляет одну строку и копирует два файла. Если блок `herwin` не найден - останавливается, ничего не меняя.
**Слоты принимают медали только после `mods/medal-slots-test`** (правила слотов в `hero.txt`). Без него слоты серые и пустые - это нормально, смотрим расположение.

## Откат
```powershell
.\uninstall.ps1 -GameDir "<папка KB The Legend EE>"
```

## Что проверить (T-22 в OWNER_TODO.md)
1. Окно героя открывается и стоит по центру, всё на месте (кнопки, рюкзак, навыки, закрытие).
2. Справа от окна видна панель «НАГРАДЫ» с шестью слотами, слоты стоят против своих подписей.
3. Окно не съехало по вертикали: игра раньше сама вписывала окно 960 px в экран 945 px, я сдвинул на 8 px вверх (`DY` в `make_panel.py`). Если низ или верх обрезан сильнее обычного - сказать «выше/ниже на N px».
4. Окно закрывается кнопкой/Esc, карта под ним не «проваливается» (клики не уходят на карту).
5. С `medal-slots-test`: медаль из рюкзака перетаскивается в слот панели.

## Если не заработало
- Окно героя не открывается / пропало: откат, прислать, что видно. Возможная причина - форма `herwin` не читает вариант под разрешение ❓ (в `forms.txt` у неё строки с разрешениями закомментированы разработчиками).
- Окно открылось, но панели нет: пришлите скриншот - тогда пробуем вариант с оригинальным `hero.ui` без явного размера.
