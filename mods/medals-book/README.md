# medals-book - панель 18 медалей в стиле игры (агент 5)

Статус: `needs-test` (в игре не запускалась). Заменяет `medals-grid` / `medals-panel` (то же имя `hero_3360x945.ui`; ставить вместо них). Превью: `preview.png` (синие рамки - родные кнопки-слоты, которые игра нарисует поверх).

## Что сделано (по запросу владельца)
- **Оформление в стиле игры:** золотая рамка с фаской и угловыми скобами-заклёпками, лоза с листьями и завитками по краям (по бокам, снизу и вдоль плашки), плашка «МЕДАЛИ» с ромбами, тёмный кожаный фон с зерном и виньеткой, золотая линия-разделитель.
- **18 карточек 6x3.** Слот 56 px (родная кнопка `slot_13..30`) в «колодце», **под слотом отдельное место под описание**: название, условие, ранги (`100к · 500к · 1М · 5М`). Сквозное правило подписи: слот №N = семья №N из `docs/achievements_legend.csv`.
- Панель справа от окна героя: x 2340..3342, y 30..664 (окно героя сдвинуто на +1040 по x, как у `medals-grid`). Фон панели - первым объектом в `hero_3360x945.ui`, под всеми слотами.
- Подсказки при наведении (`kb26_med_N`) остаются в `rus_hero.lng` (отдельный блок `kb2026 medals-book`; блок `medals-grid` при установке удаляется).

## Ограничения (честно)
- **Текст описаний нарисован в PNG**, не выводится движком: шрифт Lora (с кириллицей), а не родной шрифт игры. Менять текст: поправить `docs/achievements_legend.csv` и `python make_book.py` (нужны Python и Pillow).
- Описание привязано к **слоту**, а не к надетой медали. Пока игра не умеет класть конкретную медаль в «её» слот (автонадевание не сделано), владелец может положить любую медаль в любой из 18 слотов, и подпись не совпадёт. Динамического текста «описание выбранной медали» без новых форм в Legend нет (проба `formsolo` сломала интерфейс карты, откатана).
- Рамка и лоза нарисованы процедурно по палитре окна (золото, тёмное дерево, зелень), родные текстуры игры не использованы: файлы `interface_textures.kfs` у агента нет. Если пришлёте родные рамки/лозу, соберу панель из них (см. `tools/Extract-UiArt.ps1`, если есть, иначе `tools/extract_png.ps1`).

## Установка (на КОПИИ; сначала `medal-slots`)
```powershell
.\install.ps1 -GameDir "<копия>\KB The Legend EE"
```
Нужна `data\mods\32_9-nsf` с `forms.txt` (блок `herwin`). Откат: `.\uninstall.ps1 -GameDir "..."` (вернёт `forms.txt`, уберёт свой блок в `rus_hero.lng`, файлы панели).
