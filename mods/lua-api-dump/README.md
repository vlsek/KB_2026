# lua-api-dump - какие функции Lua реально есть в движке (агент 5)

Статус: `needs-test`. Ничего не меняет в правилах игры: при первом открытии сундука/ящика за запуск пишет в `<папка игры>\kb2026_apidump.txt` список всех пространств имён скриптов (`Game`, `Logic`, `Attack` и др.) и их функций (только имена и типы) и показывает одно окно `APIDUMP ...`.

Зачем: у нас три открытых вопроса, которые упираются в «есть ли такая функция»: автонадевание медали (`Logic.hero_lu_item_on_body`?), снятие/замена предмета при повышении ранга (`hero_remove_item` нет, кандидаты - `hero_lu_item(...,"count",0)` и др.), окно «медаль получена» и подсказки. Список закроет их одним заходом.

## Установка (от администратора, если игра в Program Files)
```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -GameDir "C:\Program Files (x86)\Blefonix Studios\KB The Legend EE"
```
Загрузить сохранение, открыть любой сундук/ящик на карте. Должно появиться окно `APIDUMP lines=... file=...`.
**Прислать:** файл `kb2026_apidump.txt` из папки игры (просто список имён, ~50-200 КБ). Если файла нет, а в окне текст - скриншот окон (до 4 штук).

## Откат
`.\uninstall.ps1 -GameDir "..."` - убирает только свои строки; другие моды в `logic_hero.lua` остаются. Бэкап: `logic_hero.lua.kb2026api.bak`.
Совместим с `ach-lua`: оба вставляют вызов после `scn_hero_takebox`. С `lua-probe` не ставить вместе (проба проще, её заменяет этот мод).

## Что проверено
Lua-код прогнан в Lua 5.1 с подставными `Game`/`Logic` (список составляется, файл пишется, при недоступном `io` показываются куски в окне). В движке Legend и под PowerShell на Windows не запускался.
