# Генераторы 32:9 (агент 1)
Python 3, нужен Pillow и numpy. Исходники — 16:9-файлы мода `16_9-nsf` (`*_1680x945.ui`) и `mainpanel_bg_1680.png` из `interface_textures.kfs`.
- `gen.py <src> <dst>` — все экраны по центру (3360 = 1680 + поля), чёрные подложки на всю ширину, строки в `forms.txt`/`resolutions.txt`.
- `dock2.py <src.ui> <dst.ui> <split_x>` — «разнести по краям»: объекты левее `split_x` остаются слева, остальные уезжают вправо на 1680. Для арены `split_x=1100`.
- `map_dock.py` — карта: три группы (левая у левого края, центр, миникарта у правого края).
- `panel3.py` + `decor3.py` — собирают широкую нижнюю панель карты из `mainpanel_bg_1680.png` (пути в аргументах) и добавляют плющ/линию.
Скрипты — основа для общего генератора под любое разрешение (Issue #2).
