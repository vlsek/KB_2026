# Мод интерфейса и камеры 32:9 (3360×945)

Версия: **v4** (из `KB_32x9_mod_v4.zip`). Автор: Агент 1.

Изменения v6: журнал заданий по центру экрана (`quests_journal_3360x945.ui`).

Изменения v4 (+арена): в бою блоки интерфейса разнесены по краям — левый верх (герой), левый низ (меню, лог), правый низ (панель кнопок), правый верх (враг).

Изменения v4: четыре кнопки панели снова вместе (в v3 сетка была разрезана); убраны медальоны, остались плющ на парапете и тонкая золотая линия; центральный блок точно по центру экрана.

## Структура
```
32_9-nsf/    → копировать В <игра>\data\mods\16_9-nsf\ (с заменой)
camera/ses/camera.txt → в <игра>\sessions\base\ses\camera.txt
README_RU.txt — оригинальная инструкция автора
```

## Установка
1. Сделай бэкап: копия `data\mods\16_9-nsf` и `sessions\base\ses\camera.txt` → `camera.txt.bak`.
2. Скопируй **содержимое** `32_9-nsf` в `data\mods\16_9-nsf`.
3. Замени `camera.txt`.
4. Выбери в игре разрешение 3360×945.

## Откат
Верни бэкапы.

## Известные проблемы / проверить
- Если нижняя панель пропала — игра не берёт `.png` из папки мода.
- Проверить артефакты камеры при `ZFAR=150` и `DIST_MAX=36`.
