# achievements-ui — интерфейс достижений для Legend под 32:9 (агент 1)

Статус: **v0 — пробный, не проверен в игре.** Часть пробного пакета `KB_32x9_mod_v7_ach.zip` (мод 32:9 + достижения).
Данные достижений (медали-предметы, счётчики) — отдельно: `mods/achievements-test` (агент 4).

## Решение по месту в интерфейсе
- **Окно героя Legend занято целиком** (духи, шкатулка, навыки, инвентарь): места под блок наград WotN (15 слотов + `achievements_bar`) нет —
  в WotN он стоит ровно там, где в Legend блок духов. Поэтому достижения делаем **отдельной книгой** (`achievements.ui`, окно 1081×765) +
  **кнопкой в окне героя** + **всплывашкой** `new_achievement` при получении. Прогресс на карте/в бою — позже, в промежутках нижней панели.
- Кнопка называется **`ahievements_button`** (опечатка как в WotN) — по этому имени, судя по всему, движок открывает книгу (в `.ui` и Lua открытия нет).
- Положение кнопки (1190, 30) в окне героя **угадано**; нужен скриншот окна героя, чтобы подобрать место.
- Кнопки публикации в соцсети (`b_publish_fb/tw/vk`) из всплывашки убраны.

## Что в пакете
`achievements_3360x945.ui`, `new_achievement_3360x945.ui` (окна по центру, явный размер 3360×945), `hero.ui` Legend + кнопка, `forms.txt` (мод 32:9 + блоки форм `achievements`, `new_achievement`).
Картинки берутся из WotN/DS скриптом `tools/extract_assets.ps1`. Генератор — `tools/ach_ui_gen.py`.
Файлы игр в репозиторий не кладём: `.ui` генерируются у владельца из его копий.
