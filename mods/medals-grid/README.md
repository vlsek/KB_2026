# medals-grid - компактная сетка медалей, 18 слотов, подсказки при наведении (агент 4)

Статус: **needs-test**. Владелец подтвердил, что 18 пазов видны и работают, медали надеваются и снимаются. Внешний вид требует доработки. Первая попытка подсказок показывала для всех пазов «Артефакт»: типовая подпись `mslot` исправлена на «Медаль», проверка ждёт перезапуска. Уникальные описания семейств ещё не работают.
Заменяет `medals-panel` (те же имена `hero_3360x945.ui`; ставить вместо него). Установщик проверен в `pwsh` 7 на копии `forms.txt` мода 32:9 (установка, повтор, удаление, побайтовый откат).

## Что изменилось
| Было (`medals-panel`) | Стало |
|---|---|
| 6 слотов по 60 px, панель 430x572 | **18 слотов по 48 px, сетка 6x3, панель 370x238** |
| подписи семей нарисованы сбоку, картинка | Подготовлены строки `kb26_med_1..18`, но нативные слоты пока выводят подсказку типа («Медаль»), а не индивидуальное описание достижения. Нужно отдельно решить способ показа описания семьи. |
| подписи надо перерисовывать | подсказки - обычный текстовый файл `rus_hero_append.txt` (меняется без картинок) |

Окно героя, как и у агента 2, сдвинуто на (+1040, -8), чтобы стоять по центру 3360x945. Панель справа от него (x 2340..2710, y 60..298), над нижней полосой карты.
Слоты 19..30 клонированы из `slot_13`. 18 семей (по порядку): Опытный герой, Полководец, Золотой запас, Архимаг, Берсерк, Исполнитель поручений, Семьянин, Скороход, Наставник духов, Тяжёлая рука, Великая армия, Истребитель, Охотник на боссов, Ветеран сражений, Враг всего живого, Высший маг, Рыцарь без книги, Без потерь (`champion` в 18 не влез).

## Установка (на КОПИИ; сначала `medal-slots`)
```powershell
.\install.ps1 -GameDir "<копия>\KB The Legend EE"
```
Нужна папка `data\mods\32_9-nsf` с `forms.txt` (блок `herwin`). Если ставился `medals-panel`: `uninstall.ps1` у него или просто поверх (файл `hero_3360x945.ui` перезапишется; лишний `medals_panel_bg.png` можно удалить).
Откат: `.\uninstall.ps1 -GameDir "<копия>\KB The Legend EE"`.

## Пересборка (нужен Python и Pillow)
`python make_grid.py` - читает `../medal-slots-ui/hero.ui` и `docs/achievements_legend.csv`, пишет `hero_3360x945.ui`, `medals_grid_bg.png`, `rus_hero_append.txt`. Размеры - константы вверху (`SLOT`, `GAP`, `COLS`, `N`).

## Что проверить (T-24)
1. Окно героя открывается, стоит по центру, всё на месте.
2. Справа вверху компактная панель «НАГРАДЫ», 18 пустых слотов (6 в ряд, 3 ряда); достаточно маленькая?
3. Наведите курсор на каждый слот: появляется подсказка с названием, условием и рангами (а не «Артефакт»).
4. С `medal-slots -TestMedals`: тестовая медаль из рюкзака встаёт в слоты 13..18 (первые 6 в сетке); в слоты 7..18 сетки (номера 19..30) - ответ нужен отдельно.
5. Размер: «меньше / больше / нормально» (и на сколько px).
