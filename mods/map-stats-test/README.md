# map-stats-test - какие поля движок подставляет в нижнюю панель карты

Автор: агент 2. Статус: **needs-test**. Чисто тестовый мод для задачи «статистика в статус-баре» (ROADMAP).

Что делает: в пустую часть нижней панели карты (x 2200..3088, y 838..932 из 3360x945) кладёт сетку 4 x 6 текстовых полей.
Каждое поле привязано к одному имени (`gui_object_text "" "<имя>"`). Если движок такое имя знает - в клетке появится число или текст, если нет - клетка пустая.
Больше мод ничего не меняет. Картинка-ключ: `key.png` (какая клетка какое имя).

| Строка | Что проверяем |
|---|---|
| 1 | контроль: поля, которые карта уже показывает (`map_money`, `map_rage`, `map_mana`, `map_level`, `map_ldrshp`, `map_hero_name`). Должны заполниться - иначе тест не годится |
| 2 | догадки в том же семействе `map_*`: атака, защита, интеллект, кристаллы, опыт, день |
| 3 | имена из окна героя (`hero_*`): работает ли поиск по имени между формами |
| 4 | статистика из `records.ui` (`rec_*`): бои, убитые враги, задания, золото, уровень, число убитых |

## Установка
1. Бэкап: скопируй `map_3360x945.ui` из `data\mods\32_9-nsf\` (папка мода 32:9) рядом под именем `map_3360x945.ui.bak`.
2. Положи сюда `map_3360x945.ui` из этой папки с заменой.
3. Игра 3360x945, загрузить сохранение или новую игру, смотреть нижнюю панель правее кнопок «Герой/Книга/Журнал/Карта».

## Что прислать
Скриншот нижней панели карты целиком. Достаточно написать, какие клетки (номера как на `key.png`, например `2.1`, `3.5`) показали значение.

## Откат
Вернуть `.bak` на место (или удалить файл, если он был только из этого мода).

## Если что-то пошло не так
- Игра вылетела при загрузке карты: откат и прислать текст ошибки / лог из папки игры.
- Пустые все клетки, включая строку 1: файл не подхватился (проверить папку мода) или поля не выводятся поверх панели - сообщить.
- Тест собран на текущем `map_3360x945.ui` агента 1 (v6). Если он изменится, пересобрать: `python make.py <новый map.ui> map_3360x945.ui key.png`.
