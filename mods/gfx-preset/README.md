# gfx-preset - безопасные графические настройки (агент 4)

Меняет только `game.ini` (с бэкапом `game.ini.kb2026.bak`), без файлов игры и DLL. Основание: `docs/GRAPHICS_RESEARCH.md` (формат строк `setf ~ключ значение` сверен с `game.ini` из Legend EE владельца; `r_vsync` там уже 1).

| Уровень | Что меняется | Риск |
|---|---|---|
| 1 | `r_filter 2` -> `5` (анизотропия 16x) | почти нулевой |
| 2 | + `shadowresolution 2048`, `r_shadowmap_landscape 1` | возможны артефакты теней, чуть ниже FPS |
| 3 | + `shadowresolution 4096` | тяжелее; только если уровень 2 чистый |

Установка на КОПИЮ игры: `.\install.ps1 -GameDir "...\KB The Legend EE" -Level 1`. Откат: `.\uninstall.ps1 -GameDir "..."`.

Что проверить и прислать (одним сообщением): запускается ли игра; скриншот карты (земля вдали) и арены до/после; FPS до/после (если считаете); есть ли артефакты теней/воды.

Не проверено в игре; PowerShell-скрипт не запускался. `r_shadowmap_landscape` лежит в `default.ini` (значение 0): применит ли игра значение из `game.ini` - проверка владельцем (если тени ландшафта не появились - значит ключ нужно править в `default.ini`).
