# achievements-test — проверка: понимает ли Legend EE медали/достижения

Автор: агент 4. Один пробный предмет-достижение **«Высший маг»** (`damage_magic` ≥ **1** — тестовый порог, в WotN 500 000).

Почему именно оно: счётчик `damage_magic` уже есть в `records.txt` Legend (это не счётчик `ma_*`, которых в Legend нет), а выражение условия `medc` во всех играх серии одинаковое. Значит, если движок Legend EE поддерживает медали, это сработает без Lua.

## Что делает установка
1. `config.txt`: `//undropable=0x0008` → `medal=0x0008` (бит medal, как в WotN).
2. `items.txt`: в начало добавляет строку `==achievements.txt` (без неё Legend файл не читает — это была причина «ничего не появилось» в первом тесте, v1).
3. Кладёт `sessions\base\ses\achievements.txt`.
4. Дописывает русские строки в конец `sessions\base\loc_ses\rus\rus_items.lng` (UTF-16).
5. Копирует иконки в `data\mods\kb2026_achievements\`.
Перед правкой — резервные копии `*.kb2026.bak`.

## Установка
```powershell
.\install.ps1 -GameDir "…\KB The Legend EE" -IconDir "…\папка_с_heroitem_achievement_*.png"
```
Откат: `.\uninstall.ps1 -GameDir "…"`. Скрипты не проверены в PowerShell (агент работает без него) — читайте перед запуском; игру лучше сначала скопировать.

## Что проверить (и записать в docs/WORKLOG.md)
| Проверка | Результат |
|---|---|
| Игра запускается, нет вылета на загрузке | ❓ |
| В новой игре/сохранении после боёв с магией (одно заклинание в бою) появляется предмет-медаль у героя | ❓ |
| Показывается название «Высший маг» и подсказка | ❓ |
| Показывается иконка | ❓ |

## Если не сработало
- Вылет на загрузке → откат, пришлите `*.log`/текст ошибки из папки игры.
- Медаль не выдаётся → движок Legend не обрабатывает `medc`; тогда путь через Lua (`Game.GVNum`/выдача предмета вручную).
- Нет иконки → png из мода не подхватывается; положить в `data\interface_textures.kfs` (zip) или искать другое место.

## После успеха
Поднять `max` до 500000 (боевой порог) в `achievements.txt`, добавить остальные 11 универсальных (см. `docs/ACHIEVEMENTS.md`, группа A).

## Где это должно показываться (открытый вопрос)
В DS есть форма-книга `achievements` (страницы + кнопка закрыть) и всплывающие `post_achievement`/`new_achievement`; в `endgame.ui` — строка со счётом достижений. Кто открывает книгу — в `.ui` и Lua не нашлось, значит это делает движок. В Legend ни формы, ни кнопки нет. v1 проверяет только факт получения; UI — следующий шаг (форма в `forms.txt` + `.ui` из DS + кнопка).
