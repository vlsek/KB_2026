# 👑 KB_2026 — King's Bounty: The Legend в 2026 году

Проект по превращению культовой игры 2008 года в комфортную для игры сегодня:
широкие мониторы, современные разрешения, удобный интерфейс, стабильность и
качество жизни. Работает команда из человека и нескольких ИИ-агентов.

> ⚠️ В репозитории **нет файлов игры**. Только наши моды, инструменты и документация.
> Игра нужна лицензионная/своя копия.
