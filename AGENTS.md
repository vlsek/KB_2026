# 🤖 Правила для агентов

Этот файл читается **первым** в начале каждой сессии любого агента.
Цель: чтобы несколько агентов и человек работали параллельно и не ломали друг другу работу.

## Порядок работы в каждой сессии

1. Прочитай `AGENTS.md`, затем последние ~10 записей [`docs/WORKLOG.md`](docs/WORKLOG.md).
2. Посмотри открытые Issues. Возьми задачу, у которой нет исполнителя (assignee / лейбл `agent:*`),
   поставь на неё свой лейбл `agent:<имя>` и статус `status:in-progress`.
3. Работай в **своей ветке**: `agent/<имя>/<кратко-о-задаче>`, например `agent/claude/ui-21x9`.
4. **Пушить в `main` можно всем агентам** (решение владельца, 2026-11-24). Ветки и PR — по желанию, для крупных или рискованных правок. Перед пушем делай `git pull --rebase`, коммиты маленькие, чужие файлы не переписывай.
5. В конце сессии добавь запись в `docs/WORKLOG.md` и обнови статус задачи.

## Зоны и конфликты

- Один мод — одна папка в `mods/<имя>/`. Не правь чужую папку без согласования в Issue.
- Общие файлы (`README.md`, `docs/ROADMAP.md`) правятся маленькими коммитами, без переформатирования.
- Если два агента хотят один и тот же файл — пишите в Issue, решает человек.

## Жёсткие правила

- 🔐 **Никаких секретов в репозитории**: токены, ключи, пароли. Если увидел — сообщи человеку, не коммить.
- 🚫 **Не коммить файлы игры** (`*.pak`, exe, оригинальные ресурсы целиком). Только наши изменённые файлы и инструменты.
- 💾 Любое изменение, которое перезаписывает файл игры, сопровождается инструкцией по откату (бэкап `.bak`).
- 🔤 **Скрипты PowerShell (`*.ps1`) — только ASCII.** Никакой кириллицы ни в комментариях, ни в строках вывода, ни в именах; тире и кавычки тоже обычные (`-`, `"`, `'`). PowerShell владельца ругается на кириллицу в скриптах. Пишите комментарии и сообщения по-английски. Проверка перед коммитом: `grep -nP '[^\x00-\x7F]' файл.ps1` должен ничего не выводить. Русский текст — в `README`/доках, не в скриптах. (Данные для игры — `.lng`, `.txt` — это не скрипты, их кодировка определяется игрой.)
- ✅ Заявлять «готово» можно только после проверки в игре человеком. До этого статус — `status:needs-test`.

## Формат коммитов

`<область>: <что сделано>` — например `ui: добавлена панель города для 21:9`, `docs: обновлён журнал`.
Области: `ui`, `camera`, `gfx`, `gameplay`, `tools`, `docs`, `repo`.

## Лейблы

- `agent:*` — кто работает; `area:*` — область; `status:*` — состояние; `prio:*` — приоритет.

## Как оставлять хендофф

В конце сессии в `docs/WORKLOG.md` добавь блок:

```
### YYYY-MM-DD — <агент> — <тема>
- Сделано: ...
- Не сделано / проблемы: ...
- Следующий шаг (кому): ...
- Ссылки: PR #, Issue #
```
